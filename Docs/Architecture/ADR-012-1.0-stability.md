# ADR-012: 1.0 stability tiers

## Status

Accepted (Phase 13)

## Context

Phases 1–12 modularized the editor into many SwiftPM products. Hosts need a clear semver contract without freezing experimental surfaces (LSP, remote extensions, SCM).

## Decision

1. Publish **Stable / Evolving / Experimental** tiers (see `Docs/Guides/API-STABILITY.md`).
2. Core editing stack (Core, Documents, LanguageSupport, View, TreeSitter, pack registration) is **Stable** for 1.0.
3. Workspace/workbench/language-services/search/tasks are **Evolving**.
4. Extensions, ExtensionHost, LSP, Terminal, SourceControl are **Experimental**.
5. Documentation and samples are part of 1.0 readiness; tagging `1.0.0` is a separate release action.

## Consequences

- Consumers can depend on Stable products with major-version guarantees.
- Experimental products remain shippable with honest churn expectations.
- Future majors concentrate on Stable breaks only.
